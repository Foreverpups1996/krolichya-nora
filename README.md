# 🐰 Кроличья нора — развивающая игра для детей 2–3 лет

Веб-игра (HTML/CSS/JS, без зависимостей) с обёрткой под Android через Capacitor.
PWA: устанавливается на домашний экран и полностью работает офлайн.

## ▶️ Играть прямо сейчас

**https://foreverpups1996.github.io/krolichya-nora/**

Работает на телефоне и компьютере — ничего устанавливать не нужно. Просто отправьте эту ссылку кому угодно. Каждый обновлённый пуш в ветку `main` автоматически публикуется на GitHub Pages (`.github/workflows/deploy-pages.yml`).

**Страница игры для родителей** (описание,FAQ): **https://foreverpups1996.github.io/krolichya-nora/parents.html**

## Принципы для 2-летних

- **Огромные кнопки** — попасть пальцем легко даже неаккуратно.
- **Никаких штрафов** — неправильный тап лишь мягко трясёт карточку и повторяет подсказку. После двух промахов правильный ответ мягко подсвечивается.
- **Сложность растёт с малышом** — сначала 2 варианта ответа, после 5 правильных подряд с первого раза — уже 3.
- **Живой голос** — подсказки и похвала записаны тёплым женским (ru) и детским (en) голосами (edge-tts). Динамические фразы озвучивает системный TTS.
- **Два языка** — русский и английский, переключается в родительской панели.
- **⭐ Наклейки** — каждые 5 звёзд дают наклейку животного в собственный альбом.
- **Родительские настройки** — кнопка «Для родителей» открывается только при удержании 3 секунды. Внутри: статистика, таймер перерывов, язык, экспорт/импорт прогресса, звук.
- **Перерывы** — родитель включает таймер (10/15/25 мин), игра мягко предлагает отдохнуть.
- **Без интернета, рекламы и покупок.** Service worker кеширует всё: игра открывается мгновенно и работает офлайн, её можно установить на домашний экран как приложение.

## Запуск в браузере

Просто откройте `www/index.html` в Chrome/Edge, либо через локальный сервер:

```bash
cd www
python -m http.server 8080
# http://localhost:8080
```

## Сборка Android APK (Capacitor)

Требования: Node.js 18+, Android Studio (или только SDK + Gradle).

```bash
cd baby-games

# 1. Инициализировать npm и поставить Capacitor
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android

# 2. Проект уже инициализирован (capacitor.config.json есть), просто добавляем платформу
npx cap add android

# 3. Скопировать веб-файлы в Android-проект
npx cap sync android

# 4. Открыть в Android Studio и собрать APK
npx cap open android
# Build → Build Bundle(s) / APK(s) → Build APK(s)
```

APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`.

Для релиза — настроить подпись (signing config) и собрать **release** APK/AAB.

### Обновление игры после сборки

```bash
npx cap sync android   # подтянуть изменения из www/
```

## Озвучка на устройстве

Основная озвучка — **предзаписанные фразы** (`www/phrases/ru/`, `www/phrases/en/`): тёплый женский голос (ru) и детский (en), сгенерированы edge-tts. Если фраза ещё не загружена или отсутствует, включается системный TTS (SpeechSynthesis):

1. установлено **Google Текстовые речевые сервисы** (Google Text-to-speech),
2. в настройках TTS скачан **русский** (или английский) пакет голосов.

На эмуляторах звук может отсутствовать — проверяйте на реальном устройстве.

Звуки животных — настоящие записи с Wikimedia Commons (список авторов и лицензий: `www/sounds/CREDITS.txt`). Форматы: MP3 (для Safari/iOS) + Ogg. Воспроизводятся мягко: чуть ускоренно (выше тище — звучит смешно, а не страшно), тихо, с плавным затуханием и ограничением по длительности. Если браузер не умеет оба формата, включается тихий синтез-фолбэк.

## Структура проекта

```
baby-games/
├── capacitor.config.json     # конфиг обёртки Android
├── www/                      # веб-часть игры (публикуется на GitHub Pages)
│   ├── index.html            # игра (OG-теги для шаринга, PWA-манифест)
│   ├── parents.html          # страница игры для родителей
│   ├── manifest.webmanifest  # PWA: установка на домашний экран
│   ├── sw.js                 # service worker: офлайн-работа
│   ├── icon-192.png / icon-512.png / apple-touch-icon.png
│   ├── share.png             # картинка для превью при шаринге
│   ├── css/style.css         # стили, анимации, конфетти
│   ├── js/
│   │   ├── i18n.js           # два языка интерфейса (ru/en)
│   │   ├── sfx.js            # синтез звуков + записи фраз + TTS + вибрация
│   │   ├── games.js          # данные и логика 8 мини-игр
│   │   └── main.js           # экраны, цикл, звёзды, наклейки, статистика, род. контроль
│   ├── phrases/ru/*.mp3      # записанные русские фразы (edge-tts)
│   ├── phrases/en/*.mp3      # записанные английские фразы
│   └── sounds/               # звуки животных (mp3 + ogg) + CREDITS.txt
└── android/                  # появится после npx cap add android
```

## Генерация медиа-ресурсов

Иконки, OG-картинка и голосовые фразы генерируются скриптами (Python: `edge-tts`, `Pillow`):

```bash
pip install edge-tts pillow
python gen_images.py     # icon-192/512, apple-touch-icon, share.png
python gen_phrases.py    # phrases/ru/*.mp3 + phrases/en/*.mp3
```

Для звуков животных Ogg → MP3 нужен ffmpeg.
